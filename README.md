# Vault Collective Testing Systems

Self-scoring IQ + personality battery. Original items, Novis-style scoring (raw + 75/70 bonus). Personal use only — not a clinical instrument, not for hiring or firing.

## Run locally
Open `index.html` in any browser. No build step, no dependencies.

## Deploy
Push to this repo and connect it to Vercel (or any static host). Single-page static site.

## Disclaimer
This is an original instrument inspired by early 20th-century aptitude/temperament questionnaires. Personal use only. No published norms, no peer-reviewed validation.
